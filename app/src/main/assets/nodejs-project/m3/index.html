📖 正则表达式速查（点击展开）
「查找」里写正则，匹配到的文本会被「替换为」的内容取代。所有匹配都会被替换（全局替换）。
写法含义例子
.任意一个字符（除换行）a.c 匹配 abc、a1c
\d  \w  \s数字 / 字母数字下划线 / 空白\d+ 匹配 123
[abc]  [^abc]字符集合 / 排除集合[0-9a-f] 匹配十六进制字符
*  +  ?0次+ / 1次+ / 0或1次colou?r 匹配 color、colour
{n}  {n,m}精确n次 / n到m次\d{4} 匹配 2026
(…)分组（捕获，可在替换里用）见下方 $1 例子
|或猫|狗 匹配「猫」或「狗」
^  $行首 / 行尾\s+$ 匹配行尾空白
\转义特殊字符\. 匹配真正的点号；\( 匹配括号
替换为含义
$1 $2…第1/2个分组捕获的内容
$&整个匹配到的文本
留空删除匹配到的内容
实用例子：
查找替换为效果
第(\d+)章第 $1 节「第3章」→「第 3 节」
sk-[A-Za-z0-9]+***抹掉 API Key
(你好|您好)[$&]「你好」→「[你好]」
\s+$(留空)删除每行行尾空白
(?i)openaiAI行内忽略大小写写法；也可用「忽略大小写」开关
注意：
  • 流式响应是按行/按片段匹配的，跨行/跨片段的规则在流式下不生效（阻塞式正常）。
  • 正则里的 . 不匹配换行符。
  • 发送方向会跳过 model 字段和图片数据（data:URL），不会误伤路由和图片。
  • 写错了正则会添加失败并提示，先点「测试」按钮本地试跑再加更稳妥。
